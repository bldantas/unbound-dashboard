# Página: index.php

## Propósito

É a página principal do painel, exibindo o status geral do sistema e links para as seções principais.

## Responsabilidades

- fornecer visão geral do estado do serviço Unbound
- mostrar métricas resumidas de desempenho
- direcionar o usuário para páginas de configuração, alertas, histórico e diagnósticos
