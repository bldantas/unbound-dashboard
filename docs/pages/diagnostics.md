# Página: diagnostics.php

## Propósito

Permite rodar diagnósticos de rede e DNS a partir do painel.

## Responsabilidades

- capturar saídas de comandos como `ping`, `traceroute`, `whois` e `dig`
- exibir resultados para análise de conectividade
- suportar execução controlada via `DiagnosticsManager`
