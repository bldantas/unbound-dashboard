# Página: health.php

## Propósito

Exibe a auditoria de saúde do sistema e permite executar a rotina de auto-reparo.

## Responsabilidades

- coletar métricas de disco, memória e carga do sistema
- verificar status do serviço Unbound
- listar componentes críticos e suas permissões
- fornecer botão para execução de `fix_health.php`
