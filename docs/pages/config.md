# Página: config.php

## Propósito

Fornece interface para configurar opções do Unbound e ajustes de rede diretamente pelo painel.

## Responsabilidades

- mostrar configurações atuais carregadas do sistema
- permitir alterações de parâmetros de DNS e de performance
- potencialmente acionar validação e reinicialização do serviço após mudanças
